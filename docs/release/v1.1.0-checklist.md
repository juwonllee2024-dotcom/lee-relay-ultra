# Lee Relay Ultra v1.1.0 release checklist

- [ ] `server/package.json` and `server/package-lock.json` report version `1.1.0`.
- [ ] `extension/manifest.json` reports version `1.1.0` and loads the shared prompt/protocol before `content.js`.
- [ ] Canonical prompt forbids fabricated evidence and native/web tools during local coding.
- [ ] One-action-per-turn parsing rejects multiple actions without executing either one.
- [ ] Browse Code `terminal_run` XML is normalized to the bounded local terminal.
- [ ] Response stability waits for generation to finish before executing a protocol block.
- [ ] Real terminal results are returned with exit code, stdout, stderr, timeout, and output-file evidence.
- [ ] Server, API, integration, and extension tests pass from a clean install.
- [ ] Workspace boundary and destructive/publishing command policies remain enforced.
- [ ] Chrome loads the extracted `extension/` directory, not the repository root or ZIP.
- [ ] Source package SHA-256 is recorded next to the final ZIP.
