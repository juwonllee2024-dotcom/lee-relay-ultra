# Lee Relay Ultra v1.0.0 release checklist

- [ ] `server/package.json` reports `lee-relay-ultra-server` version `1.0.0`.
- [ ] `extension/manifest.json` reports `Lee Relay Ultra` version `1.0.0`.
- [ ] `server/data`, `server/node_modules`, logs, environment files, and runtime outputs are not tracked.
- [ ] Server unit, API, integration, and extension tests pass from a clean install.
- [ ] Workspace-outside paths return a policy error.
- [ ] Publishing/destructive commands return a policy error before execution.
- [ ] Auto Coding without a run grant returns `403 auto_coding_required`.
- [ ] Pause, resume, stop, and loop limits are verified.
- [ ] Chrome loads `extension/manifest.json` as an unpacked MV3 extension.
- [ ] Source package SHA-256 is recorded next to the final ZIP.
